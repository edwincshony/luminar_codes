================ PYTHON MACHINE TEST =================

---------------- SECTION A (BASIC – 1 to 10) ----------------

1. Write a program to check whether a number is prime.

2. Write a program to reverse a number (without converting to string).

3. Write a program to find the largest element in a list.

4. Write a program to count vowels and consonants in a string.

5. Write a program to print Fibonacci series up to N terms.

6. Write a program to check whether a string is palindrome.

7. Write a program to remove duplicates from a list.

8. Write a program to find the sum of digits of a number.

9. Write a program to count frequency of each character in a string.

10. Write a program to print all even numbers between 1 and 100.

---------------- SECTION B (INTERMEDIATE – 11 to 18) ----------------

11. Write a program to find the second largest number in a list.

12. Write a program to sort a list without using built-in sort().

13. Write a function to check whether two strings are anagrams.

14. Write a program to merge two lists and remove duplicates.

15. Write a program to count words in a sentence using dictionary.

16. Write a program to find common elements between two lists.

17. Write a program to demonstrate list comprehension (filter even numbers).

18. Write a program to read a file and count lines, words, and characters.

---------------- SECTION C (ADVANCED – 19 to 25) ----------------

19. Write a class "Student" with attributes (name, marks) and a method to display details.

20. Extend Student class to calculate grade based on marks.

21. Write a program to handle exceptions (division by zero, invalid input).

22. Write a program to read a file and store word frequency using dictionary.

23. Write a program using lambda, map, and filter to process a list of numbers.

24. Write a program to demonstrate inheritance and method overriding.

25. Write a program to simulate a simple login system (username & password check).

---------------- BONUS (HARD 26 to 33) ----------------

26. Implement a simple bank system using OOP (deposit, withdraw, balance).

27. Write a program to find longest substring without repeating characters.

28. Implement a custom reduce() function without using functools.

29. Write a program to implement a simple calculator using functions.

30. Write a program to read a file and store word frequency using dictionary.

31. Write a program to demonstrate OOP with class and object (Student class with attributes and methods).

32. Write a program to demonstrate inheritance and method overriding.

33. Write a program to demonstrate error handling using try-except (handle division by zero and invalid input).
